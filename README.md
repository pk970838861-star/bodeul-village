# 보들마을

중학생용 픽셀 마을 게임이에요. 과목 주민 퀴즈, 오락실 미니게임, 회원 저장, 교사용 화면이 있어요.
**Vercel(무료)** 에 올리고, 회원 기록은 **구글 스프레드시트** 에 저장돼요.

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 게임 전체 (빌드 필요 없음) |
| `api/sheet.js` | 게임 ↔ 구글 스프레드시트를 이어 주는 서버 함수 |
| `api/config.js` | 어떤 기능을 켤지 게임에 알려 주는 서버 함수 |
| `google-apps-script/Code.gs` | 스프레드시트에 붙여 넣을 저장 코드 |

| 기능 | 필요한 것 |
| --- | --- |
| 게스트 혼자 놀기, 퀴즈, 오락실(컴퓨터 상대) | Vercel만 있으면 돼요 |
| 회원 저장(어느 기기에서든 이어하기), 교사용 화면 | + 구글 스프레드시트 (1단계) |
| 친구가 보이는 함께 놀기, 채팅, 친구 대결 | + Supabase 무료 (3단계, 선택) |

---

## 1단계 · 구글 스프레드시트 만들기 (5분)

1. [sheets.new](https://sheets.new) 로 새 스프레드시트를 만들고 이름을 «보들마을 기록»처럼 정해요.
2. 메뉴 **확장 프로그램 → Apps Script** 를 눌러요.
3. 원래 있던 코드를 모두 지우고 `google-apps-script/Code.gs` 내용을 붙여 넣어요.
4. 맨 위 `const TEACHER_CODE = '1234';` 의 `1234`를 **선생님만 아는 코드**로 바꾸고 저장(💾)해요.
5. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포** → 구글 계정 권한 승인
     («확인되지 않은 앱» 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동** → **허용**. 내가 만든 코드라 괜찮아요.)
6. 나온 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 을 복사해 두세요.

> 학생이 처음 회원으로 저장하면 스프레드시트에 «학생 기록» 탭이 자동으로 생겨요.

## 2단계 · Vercel에 올리기 (5분, 무료)

**방법 A: GitHub로**
1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 그대로 올려요.
2. [vercel.com](https://vercel.com) (Hobby 무료 플랜) → **Add New… → Project** → 저장소 **Import**.
3. **Environment Variables** 에 추가해요.
   - `SHEETS_WEBAPP_URL` = 1단계에서 복사한 웹 앱 URL
4. **Deploy**.

**방법 B: 명령어로**
```bash
cd bodeul-village
npx vercel
npx vercel env add SHEETS_WEBAPP_URL   # 웹 앱 URL 붙여 넣기 (Production 선택)
npx vercel --prod
```

이제 «회원으로 놀기»와 «교사용 화면»(1단계에서 정한 코드)이 켜져요.
나중에 환경 변수를 바꾸면 Vercel **Deployments → ⋯ → Redeploy** 를 눌러야 적용돼요.

## 3단계 (선택) · 함께 놀기 켜기

친구 캐릭터가 실시간으로 보이고, 채팅과 가위바위보·오목 친구 대결을 하려면 실시간 통신 서버가 필요해요.
스프레드시트로는 할 수 없어서, 무료 [Supabase](https://supabase.com) 의 실시간 기능만 빌려 써요. 표나 SQL 설정은 필요 없어요.

1. Supabase에서 **New project** 를 만들어요 (지역: Northeast Asia (Seoul) 추천).
2. **Project Settings → API** 에서 **Project URL** 과 **anon public** 키를 복사해요 (`service_role` 키는 쓰지 마세요).
3. Vercel 환경 변수에 추가하고 Redeploy 해요.
   - `SUPABASE_URL` = Project URL
   - `SUPABASE_ANON_KEY` = anon public 키

## 알아 두면 좋은 점

- **스프레드시트 «학생 기록» 탭** 에서 닉네임, 레벨, 푼 문제, 정답률, 과목별 우정, 마지막 저장 시각을 바로 볼 수 있어요. 비밀번호와 게임 데이터 열은 숨겨져 있어요. 시트 내용을 직접 고치면 학생 기록이 망가질 수 있으니 보기만 하세요.
- **비밀번호** 는 원래 숫자가 아니라 암호화한 값만 저장돼요. 비밀번호를 잊은 학생은 교사용 화면에서 «기록 지우기» 후 같은 닉네임으로 새로 가입하게 하세요.
- **저장 주기**: 놀이 중에는 20초마다, 그리고 «나가기»나 창을 닫을 때 저장돼요. 구글 Apps Script 무료 한도 안에서 한 반 규모는 충분해요.
- **Code.gs 를 고쳤다면** (예: 선생님 코드 변경) Apps Script에서 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** 를 해야 적용돼요. 웹 앱 URL은 그대로예요.
- **게스트 기록** 은 학생 기기(브라우저)에만 저장돼요.
- 무료 Supabase 프로젝트는 일주일 동안 쓰지 않으면 일시 정지돼요. 대시보드에서 **Restore** 를 누르면 다시 켜져요.
- 내 컴퓨터에서 `index.html`을 바로 열면 서버 함수가 없어서 게스트 혼자 놀기로 열려요.
